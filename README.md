# Sky Doodles

Sky Doodles is a Luanti (Minetest) mod that implements autonomous, non-interactive decorative airplanes using the **Mobs Redo** API (`mobs`).

These entities serve solely as visual sky decorations that fly at a fixed altitude of `y = 200` and leave cloud trails. They are NOT flyable, rideable, or interactive. If they crash into a mountain or each other, they will simply disappear.

## Features
- Constant fixed altitude (`y = 200`) flight path.
- Non-interactive and lightweight.
- Leaves a fading white cloud trail.
- Automatically despawns when far from players or colliding with mountains.
- Spawns occasionally with a clearance check.
